# Useful Tech Manager

Public GitHub Pages website for the Useful Tech Manager TikTok developer application.

## Pages

- `/` — official website
- `/privacy/` — Privacy Policy
- `/terms/` — Terms of Service

The site is plain static HTML and CSS with no dashboard, authentication, TikTok API connection, credentials, tokens, environment files, or build process.

## Local preview

Open `index.html` directly in a browser, or serve this directory with any static HTTP server.
